## Descripción
Sistema de consola para gestionar productos y usuarios de un restaurante.

## Estructuras de Datos Utilizadas
1. LISTA: Para almacenar todos los productos y usuarios y poder recorrerlos.
2. DICCIONARIO: Para buscar productos/usuarios por código/ID y validar duplicados.
3. TUPLA: Para definir el menú fijo del sistema que no debe modificarse.
4. CONJUNTO: Para guardar las categorías de productos sin valores repetidos.

## Instrucciones de Ejecución
1. Abrir terminal en la carpeta restaurante_app
2. Ejecutar: python main.py
